# MAP.md — Honcut 代码导航地图

> Generated by Atris | Last updated: 2026-07-23

## 项目概述

Honcut 是一个 AI 视频剪辑工作站，包含：
- **前端**：React + Vite 时间线查看器
- **后端**：Go HTTP 服务器 + MCP 工具服务器
- **存储**：SQLite（项目/时间线）、MinIO（媒体文件）、Qdrant（知识库向量）

---

## 入口点

### 开发服务器启动
```bash
# 前端（Vite dev server）
npm run dev                              # → localhost:5199

# 后端（Go HTTP 服务器）
cd server && go run cmd/honcut-server/main.go  # → localhost:8080

# MCP 服务器（stdio 传输）
cd server && go run cmd/honcut-mcp/main.go
```

### 请求生命周期
1. **前端请求** → Vite dev server (5199) → 代理到 Go API (8080)
2. **REST API** → `server/api.go:APIHandler` → `server/store.go` → SQLite
3. **MCP 工具** → `server/cmd/honcut-mcp/main.go` (stdio) → `server/mcp.go` → `server/store.go` → SQLite
4. **媒体上传** → `POST /api/upload` → `server/api.go:uploadHandler` → MinIO

### 构建流程
```bash
# 前端构建
npm run build                            # → dist/

# 后端构建
cd server && go build -o honcut-server ./cmd/honcut-server
cd server && go build -o honcut-mcp ./cmd/honcut-mcp

# Docker 构建
docker-compose build
```
